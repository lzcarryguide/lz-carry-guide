## Profile guidance policy

- A fourth-skill exclusive talent is a separate system from Exclusive Equipment. LZ Carry does not infer exclusive equipment effects from fourth-skill text.
- Skill-upgrade priorities are qualitative: prioritize utility/passives only when the stated effect is confirmed and the hero's deployment/formation requirements match the account's objective.
- Exact recommended lineups are published only if the source evidence is clear; otherwise faction, troop type and row suggestions are marked as a community recommendation requiring in-game validation.
- F2P and spending advice is based on fragment opportunity cost and role, not a universal spend tier list.
- S-rank does not automatically mean "invest now": a hero's value depends on current faction, available fragments, deployment-only skills, alternative heroes and the account's main march.
