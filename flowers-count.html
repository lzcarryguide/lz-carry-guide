Update schedule

Monday weekly reset · 00:00 AT / 02:00 UTC

The week rolls over at Monday 00:00 Apocalypse Time (UTC−2), which is 02:00 UTC. The tracker checks whether its recorded week matches the current Monday-start Apocalypse Time week and flags an old value as out of date. A new lucky number is not generated automatically; it is added after current in-game evidence is checked.

Community references agree on Monday reset; the Last Z server clock is UTC−2, so midnight Apocalypse Time is 02:00 UTC. This timing is community-documented rather than a live official API. The tracker keeps buff scope cautious where sources disagree; always check the live game before sending roses. See the Apocalypse Time schedule reference and server clock reference.

How the weekly entry is verified
  1. Capture the Lucky Rose number, buff wording and duration from the current in-game panel for the relevant week.
  2. Cross-check the same week against an independent, current community report.
  3. Record the week start, checked date, source links and any server or reset scope.
  4. If sources disagree, keep the entry Unconfirmed and show the conflict. Never infer the next number from a past rotation.

Community reports are references, not a substitute for checking the current in-game Lucky Rose panel.
